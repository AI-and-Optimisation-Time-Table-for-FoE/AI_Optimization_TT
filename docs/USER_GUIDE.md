System User Guide
This guide outlines the core workflows for the three main user roles in the AI Timetable Optimization System.

Admin Workflow

Log in to the Admin Dashboard to manage master data.

Input available lecture halls, capacity limits, and system constraints.

Trigger the Python optimization engine to generate the initial timetable draft.

Review, manually adjust if necessary, and publish the final exam and lecture schedules.

Lecturer Workflow

Access the Lecturer Dashboard using university credentials.

Submit preferred teaching hours and block out unavailable time slots.

View assigned module schedules and exam invigilation duties once published by the Admin.

Student Workflow

Log in to the Student Dashboard to view enrolled modules.

Access the finalized weekly lecture timetable and upcoming exam schedules.

Check room allocations and any real-time changes to the schedule.
